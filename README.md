## 问题记录
1. 问题：输入 `is` 命令提示 command not found
解决：正确命令是 `ls`，用来列出文件夹内文件，命令拼写不能错。

2. 问题：一开始不清楚SSH密钥的作用
解决：SSH密钥用于WSL免密安全连接GitHub，私钥保存在本机不能外传，公钥放在GitHub。

3. 问题：分不清 git commit 和 git push 的区别
