## Ch 0 · `title.js` —— 把标题洗干净

```js
export function normalizeTitle(raw) {
  if (typeof raw !== 'string') {
    throw new Error('标题必须是文字')
  }
  const title = raw.trim().replace(/\s+/g, ' ')
  if (title === '') {
    throw new Error('标题不能是空的')
  }
  return title
}
```

**这一段你学到的**：函数的三部分（参数 / 函数体 / 返回值）· `throw` 和 `return` 是两种"出去" · 坏数据挡在门口。

## Ch 1 · `task.js` —— 任务对象与列表

```js
import { normalizeTitle } from '../ch00-first-function/title.js'

function nextId(tasks) {
  let max = 0
  for (const task of tasks) {
    const n = Number(task.id.slice(1))
    if (n > max) max = n
  }
  return 't' + (max + 1)
}

export function createTask(tasks, rawTitle) {
  if (Array.isArray(tasks) === false) {
    throw new Error('tasks 必须是数组')
  }
  return {
    id: nextId(tasks),
    title: normalizeTitle(rawTitle),
    done: false,
  }
}

export function addTask(tasks, task) {
  return [...tasks, task]
}
```

**这一段你学到的**：对象（三个格子的卡片）· 数组 · `...` 展开运算符 · `import` 复用自己写的函数 · **`max = 0` 这个初始值让"空列表"自动正确，不需要额外的 if**。

## Ch 2 · `task.js` —— 改状态与删除

```js
export function findTask(tasks, id) {
  return tasks.find(task => task.id === id)
}

export function toggleTask(tasks, id) {
  if (findTask(tasks, id) === undefined) {
    throw new Error(`没有 id 为 ${id} 的任务`)
  }
  return tasks.map(task => (task.id === id ? { ...task, done: !task.done } : task))
}

export function removeTask(tasks, id) {
  if (findTask(tasks, id) === undefined) {
    throw new Error(`没有 id 为 ${id} 的任务`)
  }
  return tasks.filter(task => task.id !== id)
}
```

**这一段你学到的**：`undefined` ≠ 错误（"查"可以安静地说没有，"做"必须喊出来）· `map` 逐个换新 · `filter` 留下符合的 · `{ ...task, done: ... }` 只给目标造新对象。

## Ch 3 · `query.js` —— 过滤与统计

```js
export function filterTasks(tasks, options = {}) {
  const status = options.status ?? 'all'
  const keyword = (options.keyword ?? '').toLowerCase()

  if (status !== 'all' && status !== 'done' && status !== 'todo') {
    throw new Error(`status 只能是 all、done 或 todo，收到的是 "${status}"`)
  }

  return tasks.filter(task => {
    if (status === 'done' && task.done === false) return false
    if (status === 'todo' && task.done === true) return false
    if (keyword !== '' && task.title.toLowerCase().includes(keyword) === false) return false
    return true
  })
}

export function summarize(tasks) {
  const done = tasks.filter(task => task.done === true).length

  return {
    total: tasks.length,
    done,
    todo: tasks.length - done,
  }
}
```

**这一段你学到的**：`??` 和 `||` 的区别（"没给"vs"给了空"）· 用连续 `if ... return false` 表达"并且" · `if (...) return false` 里写的是**我不要谁** · 派生数据不落盘（能算出来的不要存）。

## Ch 4 · `render.js` / `args.js` —— 打印列表与读懂命令行

```js
// render.js
export function renderList(tasks) {
  if (tasks.length === 0) {
    return '（还没有任务）'
  }

  const idwidth = Math.max(...tasks.map(task => task.id.length))

  return tasks
    .map(task => {
      const box = task.done ? '[x]' : '[ ]'
      return `${task.id.padEnd(idwidth)}  ${box}  ${task.title}`
    })
    .join('\n')
}

// args.js
const COMMANDS = ['add', 'list', 'done', 'remove']

export function usage() {
  return '用法：node src/cli.js <add|list|done|remove> [参数...]'
}

export function parseArgs(argv) {
  const [command, ...args] = argv

  if (command === undefined) {
    throw new Error(`还没输入命令。${usage()}`)
  }
  if (COMMANDS.includes(command) === false) {
    throw new Error(`不认识命令 "${command}"。${usage()}`)
  }
  return { command, args }
}
```

**这一段你学到的**：先把最长的 id 量出来（`Math.max(...)` + `.map`）再用 `.padEnd` 补齐，列才会对齐 · 空列表要给一句人话 · 命令表做成常量，校验和报错都引用它（加命令只改一处）· 报错时顺手带上用法。

## Ch 5 · `store.js` —— 存盘与读盘

```js
import { readFile, writeFile } from 'node:fs/promises'

export async function loadTasks(path) {
  try {
    const text = await readFile(path, 'utf8')
    const data = JSON.parse(text)
    return Array.isArray(data) ? data : []
  } catch (error) {
    if (error.code === 'ENOENT') {
      return []
    }
    throw error
  }
}

export async function saveTasks(path, tasks) {
  const text = JSON.stringify(tasks, null, 2) + '\n'
  await writeFile(path, text, 'utf8')
}
```

**这一段你学到的**：读写硬盘是异步的，所以函数是 `async`、调用要 `await` · 「文件不存在」（`ENOENT`）是正常情况、返回空数组，其它错误原样抛出**不能吞掉** · `JSON.stringify(tasks, null, 2)` 加换行结尾，文件才是人可读、结尾干净的。
