# 我学过的固定格式（Ch 0 – Final）

> **怎么用这份表**：写代码时先找句型 → 填名字和值。**标点是句型的一部分，不用临时决定要不要加。**
> 每条都标了"出自哪一章"，例子全部来自**你自己写过的代码**。
> 最后两节：运算符速查、报错读法、默写清单。

---

## 0. 三条铁律（先记这三条，能省掉大半报错）

**① 配对法**：每写下一个左半边，**立刻**把右半边也写下来，再回到中间填内容。

| 写了 | 立刻补 |
|---|---|
| `(` | `)` |
| `{` | `}` |
| `[` | `]` |
| `'` | `'` |
| `` ` `` | `` ` `` |

**报错只会告诉你"哪个符号不对"，永远不会告诉你"少了一个"。** 先配对，就永远不会缺。

**② 本项目不写分号**：一行结尾不写 `;`。**少一个决策点。**

**③ 中文标点一律不行**：`，` `。` `"` `"` `'` `'` `（` `）` 都不认——必须英文半角。
（写代码前把输入法切成英文：按 `Shift` 或 `Ctrl+空格`。）

## 1. 定义一个函数

```js
export function 名字(参数1, 参数2) {
  要做的事
}
```

- 出自 **Ch 0**（`normalizeTitle`）、**Ch 1**（`createTask` / `addTask`）、**Ch 2**（三个函数）
- 标点：名字**紧贴** `(`；`)` 后面**一个空格**再 `{`；结尾 `}` 独占一行
- **不给外面用**的内部工具就不写 `export`（Ch 1 的 `nextId` 就是这样）
- 没有参数也要写 `()`；没有动作也要写 `{}`

## 2. 调用一个函数

```js
名字(参数1, 参数2)
名字()
```

- 出自 **Ch 0**：`normalizeTitle(rawTitle)`
- 出自 **Ch 1**：`Array.isArray(tasks)`、`Number(task.id.slice(1))`
- 标点：名字**紧贴** `(`，一个都不能少

## 3. 拿别人的东西 / 交出去

```js
import { 名字 } from './别的文件.js'
export function 名字() { }
```

- 出自 **Ch 1**：`import { normalizeTitle } from '../ch00-first-function/title.js'`
- 标点：**`.js` 后缀不能省**；`./` = 同目录，`../` = 上一级；花括号里写要拿的名字

## 4. 定义一个值（常量 / 变量）

```js
const 名字 = 值      // 以后不再改它（首选）
let 名字 = 值        // 后面会改（比如循环里记最大值的 max）
```

- 出自 **Ch 0**：`const title = raw.trim().replace(/\s+/g, ' ')`
- 出自 **Ch 1**：`let max = 0`（因为循环里要更新它）
- 标点：`const` 后面一个空格，名字后面**空格 + 等号 + 空格**

## 5. 对象（一张卡片）

```js
{
  键1: 值1,
  键2: 值2,
}
```

- 出自 **Ch 1**：

```js
  return {
    id: nextId(tasks),
    title: normalizeTitle(rawTitle),
    done: false,
  }
```

- 标点：键和值之间是**冒号 `:`**（不是等号！）；每一对之间是**逗号**；最后一个也留逗号没关系
- ⚠️ **键不是变量**：`{ total: tasks.length }` 左边的 `total` 只是个格子名，别处不能当变量用（Ch 3 你踩过这个）

## 6. 数组（一排东西）

```js
[项目1, 项目2]
[]                    // 空数组
[...一排, 新东西]      // 把原来倒出来，再放新的
```

- 出自 **Ch 1**：`return [...tasks, task]`
- 标点：项目之间是逗号；`...` 是**三个点**，紧贴数组名

## 7. if（判断）

```js
if (条件) {
  条件成立时做的事
}
```

一句话的版本（`filter` 里常用）：

```js
if (条件) return false
```

带 else：

```js
if (条件) {
  ...
} else {
  ...
}
```

- 出自 **Ch 0**：`if (typeof raw !== 'string') { throw ... }`
- 出自 **Ch 2 / Ch 3**：`if (status === 'todo' && task.done === true) return false`
- 标点：**条件永远被 `( )` 包住**；要执行的内容被 `{ }` 包住

## 8. 抛错

```js
throw new Error('给人看的一句话')
throw new Error(`带变量的：没有 id 为 ${id} 的任务`)
```

- 出自 **Ch 0**：`throw new Error('标题不能是空的')`
- 出自 **Ch 2**：``throw new Error(`没有 id 为 ${id} 的任务`)``
- 读法：`throw` = 退货报警；`return` = 正常出货。**坏数据要用 throw 喊出来。**

## 9. for...of（一个一个过）

```js
for (const 每一项 of 那一排) {
  对每一项做的事
}
```

- 出自 **Ch 1**：

```js
  for (const task of tasks) {
    const n = Number(task.id.slice(1))
    if (n > max) max = n
  }
```

- 标点：`const` 后面是**单数**（每一轮拿到的那一个），`of` 后面是**复数**（要遍历的那一排）；中间是 `of`，不是逗号
- ⚠️ 名字写反了不报错，只是**算出来的结果是错的**（你在 Ch 1 踩过）

## 10. 箭头函数（短函数）

```js
参数 => 结果
(参数1, 参数2) => 结果
```

- 出自 **Ch 2**：`tasks.find(task => task.id === id)`
- 出自 **Ch 3**：`tasks.filter(task => { ... })`
- 读法：左边是"拿到的每一条"，右边是"给它算点什么"

## 11. 三元运算符（二选一）

```js
条件 ? 真的值 : 假的值
```

- 出自 **Ch 2**：

```js
  tasks.map(task => (task.id === id ? { ...task, done: !task.done } : task))
```

- 读法：`?` 前是问题，`?` 后是真话答案，`:` 后是假话答案

## 12. 对象展开 + 覆盖一个格子

```js
{ ...原对象, 键: 新值 }
```

- 出自 **Ch 2**：`{ ...task, done: !task.done }`
- 读法：把原卡片所有格子倒出来，再**覆盖**指定的那一个 → 得到**新卡片**，原卡片没动

## 13. 点号（打开格子 / 使用能力）

```js
对象.键
值.能力(参数)
```

- 出自 **Ch 1**：`task.id`
- 出自 **Ch 3**：`task.title.toLowerCase().includes(keyword)`
- 标点：是**点 `.`**，不是逗号（Ch 1 你把它写成了逗号）
- 链式：`.toLowerCase().includes(...)` —— 前一个的结果继续用后面的能力

## 14. 数组自带能力（学过的四个）

| 写法 | 干什么 | 出自 |
|---|---|---|
| `tasks.length` | 有几条（**不是函数，不加括号**） | Ch 1 |
| `tasks.find(f)` | 找出**第一个**满足的（找不到 → `undefined`） | Ch 2 |
| `tasks.map(f)` | 每一条都**换成新的**（新数组，长度不变） | Ch 2 |
| `tasks.filter(f)` | **留下**满足条件的（新数组，可能变短） | Ch 2 / Ch 3 |

## 15. 字符串自带能力（学过的六个）

| 写法 | 干什么 | 出自 |
|---|---|---|
| `.trim()` | 去掉首尾空白 | Ch 0 |
| `.replace(找什么, 换成什么)` | 替换 | Ch 0 |
| `.toLowerCase()` | 全变小写 | Ch 3 |
| `.includes(文字)` | 我里面包含这段吗 → `true`/`false` | Ch 3 |
| `.slice(1)` | 从第 1 个位置开始取（砍掉开头那个字） | Ch 1 |
| `.length` | 有几个字（**不加括号**） | Ch 1 |

## 16. 运算符速查

| 写法 | 读法 |
|---|---|
| `=` | 赋值：把右边放进左边 |
| `===` | 相等吗（本项目统一三个等号） |
| `!==` | 不相等吗 |
| `!x` | 取反（`true` ↔ `false`） |
| `>` `<` | 大于 / 小于 |
| `+` | 相加 / 拼接文字 |
| `??` | **左边是 `null`/`undefined` 时**才用右边（Ch 3） |
| `&&` | 并且 |
| `\|\|` | 或者（⚠️ 它会把 `''`、`0`、`false` 也当"没给"） |
| `...` | 展开：把一排东西倒出来 |

## 17. 报错读法（读三样：文件、行号、箭头）

| 报错 | 先查什么 |
|---|---|
| `SyntaxError: Unexpected token …` | **标点**：括号/引号没配对、用了中文标点 |
| `SyntaxError: Unexpected end of input` | **少了**收尾的 `)` `}` `]` 或引号 |
| `ReferenceError: xxx is not defined` | **名字**：拼错 / 从没声明过 / 忘了 `import` |
| `TypeError: xxx is not a function` | **名字**拼错，或那东西根本不是函数 |
| `Cannot find module '...'` | 文件路径写错，或文件还没创建 |

## 18. 默写清单（10 个句型，想练就照着打）

1. 定义一个带两个参数、并且给外面用的函数
2. 定义一个不让外面用的内部函数
3. `import` 一个名字进来
4. 一行 `if` + `throw`（用模板字符串）
5. 一行 `if` + `return false`
6. `for...of` 循环
7. `return` 一个三格的对象
8. `return [...一排, 新东西]`
9. 箭头函数 + 三元（挑一个格子覆盖）
10. 用点号链：`某物.能力1().能力2(参数)`

## 19. Ch 4 – Final 新学的格式

| 写法 | 干什么 | 出自 |
|---|---|---|
| `.padEnd(长度)` | 不够长就在右边补空格（列对齐） | Ch 4 |
| `Math.max(...一排)` | 从一排数字里取最大的（`...` 把数组摊开） | Ch 4 |
| `process.argv` | 命令行里敲的字组成的数组 | Ch 4 |
| `const [a, ...rest] = 数组` | 拆开数组：第一个给 a，其余给 rest | Ch 4 |
| `.includes(x)`（数组） | 这一排里有 x 吗 → `true`/`false` | Ch 4 |
| `async function` | 声明"这函数里要等异步的事" | Ch 5 |
| `await 某事` | 等它做完再往下走（只能在 `async` 里用） | Ch 5 |
| `try { } catch (error) { }` | 可能失败的代码放 try，失败的收尾放 catch | Ch 5 |
| `readFile(路径, 'utf8')` / `writeFile(路径, 文本, 'utf8')` | 读 / 写文件（来自 `node:fs/promises`） | Ch 5 |
| `JSON.parse(文本)` / `JSON.stringify(值, null, 2)` | 文本 ↔ 对象互转（2 = 缩进两格） | Ch 5 |
| `error.code === 'ENOENT'` | 判断"文件不存在"这种正常情况 | Ch 5 |

**两条新铁律**：

- **`await` 只能在 `async` 函数里用** —— 忘了写 `async`，报错会指向 `await` 那一行。
- **`async` 函数的返回值永远是 Promise** —— 在外面拿结果也要 `await`。
