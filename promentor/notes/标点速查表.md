# JavaScript 标点速查表（mini-todo 课程专用）

> 打印出来或开着看都行。**所有句型都长这样，标点是句型的一部分，不是你要临时决定的。**
> 这份表只收录本课程会用到的句型。遇到没见过的，问 ProMentor。

---

## 0. 第一条规则（最重要）：配对

**每写下一个"左半边"，立刻把"右半边"也写下来，然后再回到中间填内容。**

| 你写了 | 立刻补上 | 也叫 |
|---|---|---|
| `(` | `)` | 小括号（圆括号） |
| `{` | `}` | 大括号（花括号） |
| `[` | `]` | 方括号 |
| `'` | `'` | 单引号 |
| `` ` `` | `` ` `` | 反引号（键盘左上角，Esc 下面） |
| `/*` | `*/` | 块注释 |

为什么这条最重要？因为**报错永远只告诉你"哪个符号有问题"，不会告诉你"少了一个"**。
少了括号时，报错往往指在**下一行**，你会看得一头雾水。**先配对，就永远不会缺。**

## 1. 函数

```js
function 名字(参数1, 参数2) {
  函数体
}
```

- `function` 后面**一个空格**，然后是名字
- 名字后面**紧跟 `(`**，参数之间用 **逗号** 分隔
- `)` 后面**一个空格**，然后 `{`
- 结尾必须有 `}`（独占一行，和 `function` 对齐）

**只给外面用的函数，前面加 `export `：**

```js
export function createTask(tasks, rawTitle) {
}
```

**箭头函数**（短到可以塞进一行的函数）：

```js
(参数) => 结果
```

例子：
```js
tasks.find(task => task.id === id)          // 一个参数时，括号可省
tasks.map(task => task.id)                  // 同上
(增加, 减少) => 增加 + 减少                  // 两个参数，括号不能省
```

---

## 2. if（条件判断）

```js
if (条件) {
  条件成立时做的事
}
```

带 else：

```js
if (条件) {
  成立时
} else {
  不成立时
}
```

- **条件永远被 `( )` 包住**
- 要执行的内容永远被 `{ }` 包住
- `} else {` 写在同一行是惯例（不是必须）

**一句话的 if 可以不带大括号**（本课程少用，但你会看到）：

```js
if (n > max) max = n
```

---

## 3. for...of（一个一个过）

```js
for (const 每一项 of 那一排) {
  对每一项做的事
}
```

例：

```js
for (const task of tasks) {
  console.log(task.title)
}
```

- `const` 后面是**单数**（每一轮拿到的那一个）
- `of` 后面是**复数**（要遍历的那一排）
- 两个名字之间是 `of`，不是逗号

---

## 4. 对象（一张卡片）

```js
{
  键1: 值1,
  键2: 值2,
}
```

例：

```js
{ id: 't1', title: '买牛奶', done: false }
```

- 键和值之间是 **冒号 `:`**（不是等号！）
- 每一对之间是 **逗号 `,`**
- **最后一个也写逗号是可以的**（叫 trailing comma，本课程都写，方便以后加东西）
- 整张卡片被 `{ }` 包住

---

## 5. 数组（一排东西）

```js
[项目1, 项目2, 项目3]
```

- 项目之间是 **逗号**
- 整体被 `[ ]` 包住
- **空数组**是 `[]`（中间什么都不写）

**展开运算符**（把一排东西"倒出来"）：

```js
[...tasks, 新的一张]
```

- `...` 是**三个点**，紧贴在数组名前面（中间不能有空格）

---

## 6. 字符串（文字）

三种写法，**头尾必须同款**：

```js
'单引号'
"双引号"
`反引号里可以放 ${变量}`
```

- 本项目统一用**单引号**（除了需要嵌东西时）
- ⚠️ **中文输入法的引号不行**：`'` `"` 是中文的，JS 不认！写代码前把输入法切成英文
- 一句话里出现引号本身时，要换一种（或用 `\` 转义），例如 `"it's"`

---

## 7. 调用函数

```js
函数名(参数1, 参数2)
```

- 名字后面**紧跟 `(`**，即使没有参数也要写 `()`：`usage()`

---

## 8. 返回 / 抛错

```js
return 值          // 出货：把结果交出去，函数结束
return             // 什么都不交（得到 undefined）
throw new Error('说明')   // 报警：出错了，交给调用方处理
```

- `new Error(...)` 里是**一个括号、一个字符串**
- `throw` 后面的代码不会执行

---

## 9. 点号（打开格子 / 使用能力）

```js
task.id            // 打开 task 这张卡片的 id 格子
task.id.slice(1)   // 对那个值"使用 slice 这个能力"
```

- 是**点 `.`**，不是逗号，不是分号
- 逗号 `,` 是"并列两样东西"，点 `.` 是"进入里面" —— **两个完全不同的意思**

---

## 10. 三元运算符（简短的 if/else 表达式）

```js
条件 ? 成立时的值 : 不成立时的值
```

例：

```js
task.done ? '[x]' : '[ ]'
```

- 问号 `?` 和冒号 `:` 都是**英文半角**
- 长这样的时候，冒号前面**没有空格要求**，但两边留空格更好读

---

## 11. 分号：**本项目不写**

好消息：这个项目**一行结尾不写 `;`**。JS 会自动补上。

所以**你完全不用纠结分号**——省掉一个决策点。

---

## 12. 缩进（空格）：不是给 JS 看的，是给你自己看的

- JS 不在乎缩进，全写一行也能跑
- 但缩进告诉你**谁属于谁**：同一个 `{ }` 里的语句缩进一样
- 惯例：**每进一层缩进 2 个空格**

---

## 13. 报错信息速查

| 报错里的话 | 通常意味着 |
|---|---|
| `SyntaxError: Unexpected token '}'` | 多了一个 `}`，或者少了 `)` `]` |
| `SyntaxError: Invalid or unexpected token` | 引号没关上 / 用了中文标点 |
| `SyntaxError: Unexpected end of input` | 少了收尾的 `}` `)` `]` 或引号 |
| `xxx is not defined` | 用了一个不存在的名字（打错字，或没 import） |
| `xxx is not a function` | 那个东西不是函数（名字写错，或值不对） |
| `Cannot find module '...'` | 路径写错，或文件还没创建 |

**读报错三件套：① 哪个文件 ② 哪一行 ③ 箭头指着哪个字符。**

---

## 14. 写新东西的固定流程（照这个做就不会卡）

1. **先敲骨架，不填内容**：`function xxx() {}` → 光标回到 `{}` 中间
2. **配对检查**：每次敲 `(` `{` `[` `'`，立刻补右半边
3. **想清楚要几个参数、返回什么**（写在注释里也行）
4. **一次只写一小步，写完立刻跑测试**
5. **红了不怕**：只看第一条 ✖ 和"期望 X，得到 Y"

---

## 15. 背不下来的话

**照着抄不是罪。** 但要按这三个台阶走：

```
① 抄一遍（注意标点是怎么配对的）
② 改一点（把变量名换掉、值换掉，跑测试看还对不对）
③ 从空文件写（这时候你已经抄过 5-10 遍了）
```

你现在在 ①。**这是必经之路，不是能力问题。**
